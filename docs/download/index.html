The honest part

About that Gatekeeper warning

Compass isn't notarized yet. That's not an oversight — it's arithmetic: Apple charges $99/year for notarization, and Compass currently makes $0. The moment sponsors cover it, every future build is signed and your Mac trusts it out of the box. It's on the roadmap, in the open.

Until then, the first launch is a two-second ritual: right-click the app → Open → Open. You've done this before — it's the standard open-source Mac experience, and the source is right there if you'd rather verify first and build it yourself.

Apple Silicon Mac
macOS 26 (Apple Silicon)

First launch

Compass indexes your project and downloads the local model. Local completion, chat, and search work immediately — offline, no keys needed.

Agentic coding

Add your own API key (OpenRouter, Kilo, DeepSeek, any OpenAI-compatible endpoint) and the full agentic pipeline lights up. Your key, your bill.
